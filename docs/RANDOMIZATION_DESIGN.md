# 物体物理属性随机化设计文档

## 概述

本文档详细说明了 LinkerPenspin 项目中针对转笔技巧（Triangle Pass、Thumb Around、Index Bust）优化的物理属性随机化策略。

## 目标技巧分析

### Triangle Pass（三角传递）
- 笔在食指、中指、无名指之间连续传递
- 关键物理交互：滚动摩擦、侧向推动
- 敏感参数：摩擦系数（决定抓握稳定性）

### Thumb Around（拇指旋转）
- 笔绕拇指旋转一周
- 关键物理交互：离心力、角动量守恒
- 敏感参数：质量分布、惯量

### Index Bust（食指弹击）
- 食指弹击笔使其旋转
- 关键物理交互：冲击传递、弹性碰撞
- 敏感参数：恢复系数、摩擦系数

## LinkerPen 物理特性

基于 `assets/cylinder/linkerpen/pen_gen.py` 的设计：

| 属性 | 值 | 说明 |
|------|-----|------|
| 总长度 | 180 mm | 标准转笔长度 |
| 半径 | 9 mm | 笔身半径 |
| 总质量 | ~40.93 g | 24.39g (笔身) + 8.27g×2 (端头) |
| 笔身材料 | 尼龙 | 密度 1150 kg/m³ |
| 端头材料 | 铝合金 | 密度 2710 kg/m³ |

## 随机化参数设计

### 1. 质量随机化

```yaml
randomizeMass: True
randomizeMassLower: 0.035   # 35g (-15%)
randomizeMassUpper: 0.048   # 48g (+17%)
```

**设计理由：**
- URDF 定义的精确质量：40.93g
- 真实世界变化：不同笔的重量差异、配重调整
- ±15-17% 范围覆盖常见转笔笔重（35-48g）

**实现方式：**
- 读取 URDF 原始质量
- 计算缩放因子 = 目标质量 / URDF 质量
- 同时缩放质量和惯量张量（保持动力学一致性）

### 2. 质心随机化

```yaml
randomizeCOM: True
randomizeCOMLower: -0.002   # ±2mm
randomizeCOMUpper: 0.002
```

**设计理由：**
- 模拟制造公差和配重不均匀
- 真实笔的质心偏移通常在 ±2mm 以内
- 转笔技巧对质心位置敏感（影响旋转平衡点）

### 3. 摩擦系数随机化

```yaml
randomizeFriction: True
randomizeFrictionLower: 0.4   # 最小摩擦（光滑表面）
randomizeFrictionUpper: 1.2   # 最大摩擦（粗糙表面）
```

**真实物理参考：**
| 材料组合 | 摩擦系数范围 |
|----------|--------------|
| 尼龙-橡胶 | 0.3-0.6 |
| 铝-橡胶 | 0.4-0.8 |
| 塑料-皮肤 | 0.4-1.0 |
| 金属-皮肤 | 0.3-0.7 |

**设计理由：**
- 原范围 [0.3, 3.0] 过宽，3.0 接近"粘连"行为
- 新范围 [0.4, 1.2] 覆盖常见手指-笔交互场景
- 下限 0.4：光滑塑料表面
- 上限 1.2：适度粗糙表面（含安全边际）

### 4. 恢复系数随机化

```yaml
randomizeRestitution: True
randomizeRestitutionLower: 0.1   # 低弹性
randomizeRestitutionUpper: 0.5   # 中等弹性
```

**真实物理参考：**
| 材料组合 | 恢复系数范围 |
|----------|--------------|
| 塑料-软组织 | 0.2-0.4 |
| 金属-软组织 | 0.3-0.5 |
| 橡胶-橡胶 | 0.4-0.7 |

**设计理由：**
- 原范围 [0, 1] 不合理：0 = 完全非弹性，1 = 完全弹性
- 转笔时不希望过度弹跳（会导致失控）
- 新范围 [0.1, 0.5] 模拟真实手指-笔碰撞
- 偏低的恢复系数有助于稳定抓握

### 5. 缩放参数

```yaml
randomizeScale: True        # 保持 True（缓存加载条件需要）
randomizeScaleList: [1.0]   # 固定为 1.0
randomizeScaleLower: 1.0
randomizeScaleUpper: 1.0
```

**设计理由：**
- LinkerPen 使用真实尺寸设计，不需要缩放
- 保持 randomizeScale=True 是为了兼容 DOF 缓存加载逻辑
- 所有缩放值锁定为 1.0

## Sim2Real 迁移考虑

### 参数敏感性分析

| 参数 | Sim2Real 影响 | 建议策略 |
|------|---------------|----------|
| 质量 | 中等 | 适度随机化，真实系统可精确测量 |
| 质心 | 高 | 保守随机化，真实系统难以精确校准 |
| 摩擦 | 极高 | 较宽范围，真实值高度依赖环境条件 |
| 恢复系数 | 高 | 中等范围，真实碰撞行为复杂 |

### 训练建议

1. **初始训练**：使用默认随机化范围
2. **微调阶段**：根据真实机器人表现调整范围
3. **部署前**：测量真实参数，使用窄范围进行最终微调
